# Code of Conduct

Plan Atlas adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be welcoming, patient and respectful. People here have different backgrounds, languages and levels of experience.
- Criticise ideas, not people. Give and accept constructive feedback gracefully.
- No harassment, insults, sexualised language or imagery, personal attacks, or publishing others' private information.

## Scope

This applies in all project spaces (issues, pull requests, discussions, chat) and when you represent the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the maintainer, GitHub user **thanhson0514**, or through a private GitHub Security Advisory on the repository marked "Code of Conduct". Every report is reviewed promptly and kept confidential.

Maintainers may remove comments, commits or contributions, or temporarily or permanently ban anyone whose behaviour they judge inappropriate, following the enforcement guidelines of the Contributor Covenant.
